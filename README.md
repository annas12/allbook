# AllBook

Website ringkasan buku bestseller berbahasa Indonesia.

## Fitur
- Mobile-first responsive layout
- Pencarian judul, penulis, dan topik
- Filter kategori
- Ringkasan dalam modal tanpa pindah halaman
- Ide utama + langkah praktis tiap buku
- Cover menggunakan aset dari repo `annas12/lp1`

## Deploy
Repo ini berupa static site. Aktifkan GitHub Pages dari branch `main` / root, atau hubungkan ke Cloudflare Pages.

## Menambah buku
Tambahkan object baru pada array `books` di `index.html`.
